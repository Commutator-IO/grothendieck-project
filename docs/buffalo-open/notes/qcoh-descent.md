# Universal effective epimorphisms of schemes and descent of quasi-coherent sheaves

Notes on the question raised at 6:26 in Grothendieck's 1973 Buffalo lectures (video `3ULFIl_2Wis`).

Short answer:

- Every universal effective epimorphism of schemes is a **descent** morphism for QCoh: the pullback functor is fully faithful (Thm A, proved here).
- Every **quasi-compact** universal effective epimorphism is an **effective** descent morphism for QCoh (Thm B). This is due to Mesablishvili (2004); a self-contained proof is given below.
- The affine case: `Spec B → Spec A` is a universal effective epimorphism in Sch ⇔ the same in Aff ⇔ `A → B` is pure (universally injective).
- The non-quasi-compact case fails, at least under an extra set-theoretic hypothesis. If some nonprincipal ultrafilter on the set of primes is generated by ℵ₁ sets (for instance under CH), then the Stacks Project's family `{Spec ℤ_A → Spec ℤ}_{A∈U}` is a universal effective epimorphism of schemes. Its pullback functor is fully faithful but not essentially surjective (Thm C).
- I do not know a ZFC counterexample. In the van Douwen–Kunen–van Mill model, the obstruction used in Thm C vanishes for every U.

- **Precise form of the question studied here.** Given a universal effective epimorphism f : X → Y in Sch, or a universally effective-epimorphic family (equivalently, its coproduct morphism, since coproducts in Sch are disjoint and universal):
  - is f a descent morphism (rank 1) for QCoh?
  - is f an effective descent morphism (rank 2) for QCoh?

Terminology used throughout:

- In a category with fibre products, effective epi = regular epi = strict epi.
- "Universal effective epimorphism" = "stable regular epimorphism" (Mesablishvili's term) = a single-arrow covering of the canonical topology.

## 2. The affine case

**Prop 1.** For a ring map A → B, the following are equivalent:

- (a) Spec B → Spec A is a universal effective epimorphism in Sch;
- (b) it is a universal effective epimorphism in Aff;
- (c) for every A-module M, the sequence M → M⊗B ⇉ M⊗B⊗B is an equalizer;
- (d) A → B is pure (universally injective);
- (e) A → B is an effective descent morphism for modules;
- (f) A → B is a descent morphism for modules.

Proof:

- (a)⇒(b): Aff ⊂ Sch is full and closed under fibre products, so base changes and test objects can be restricted to affines.
- (b)⇔(c): Stacks **Lemma 0EUA**, applied to the one-member family. The proof of (b)⇒(c) uses the base change along Spec(A⊕M) and the test object 𝔸¹.
- (c)⇒(d): trivial.
- (d)⇔(e)⇔(f): Stacks **Theorem 08XA** (Section 08WE). This is the Joyal–Tierney theorem; Mesablishvili, TAC 7 (2000), gives a published proof.
- (d)⇒(a): Mesablishvili, *More on descent theory for schemes*, Georgian Math. J. 11 (2004) 783–800 (read):
  - Thm 5.7 / Cor 5.8: a pure morphism of affine schemes is a regular epimorphism in SCH. The proof uses Prop 5.6 (surjectivity), then glues local affine pieces.
  - Cor 5.10: stability under base change.

So nothing changes when Aff is replaced by Sch: the affine universal effective epimorphisms are exactly the pure maps.

**Mesablishvili 2004** proves more:

- Thm 5.11: a **quasi-compact** morphism of schemes is pure iff it is a stable regular epimorphism in SCH.
- Its introduction attributes to his ACS 12 (2004) paper the result that a quasi-compact morphism is pure iff it is a stable effective descent morphism for QCoh.

I did not obtain the ACS paper. Thm B below gives an independent proof of the needed direction.

(Schröer's arXiv note math/0106081, *Effective descent maps for schemes*, is withdrawn: "mistakes in the proofs for Proposition 1.2 and Theorem 2.2". Do not cite it.)

## 3. Positive results

**Thm A.** Every universal effective epimorphism f : X → Y of schemes is a descent morphism for QCoh: f* : QCoh(Y) → Des(f) is fully faithful. No quasi-compactness is needed.

Proof.

1. The question is Zariski-local on Y: Hom-sheaves glue, and a base change of a universal effective epimorphism to an open of Y is again one. So assume Y = Spec A.
2. Let F be quasi-coherent on Y, put Y' = Spec(O_Y ⊕ F) (square-zero extension), and X' = X ×_Y Y'.
3. As sheaves on |X| = |X'| we have O_{X'} = O_X ⊕ f*F, so Γ(X',O) = Γ(X,O) ⊕ Γ(X,f*F). The same holds on X'×_{Y'}X'. This step needs no affineness of X.
4. Test the effective epimorphism X' → Y' against 𝔸¹ (Mor(T,𝔸¹) = Γ(T,O_T)). Taking the F-components gives the exact sequence
   Γ(Y,F) → Γ(X,f*F) ⇉ Γ(X×_Y X, f*F).
5. That sequence is Hom_Y(O,F) = Hom_{Des}(f*O, f*F).
6. Both Hom(–,F) and Hom_{Des}(f*–, f*F) turn direct sums and cokernels into products and kernels, because f* preserves colimits. A presentation O^(I) → O^(J) → M → 0 then gives the result for every M. ∎

**Thm B.** Every quasi-compact universal effective epimorphism f : X → Y is an effective descent morphism for QCoh.

Proof.

1. **Reduce to Y = Spec A.** Effectiveness is Zariski-local on Y once full faithfulness is known (Thm A): the descended objects on an open cover glue by uniqueness. This is Grothendieck's own 8629 and 8760.
2. **A finite affine cover.** X is quasi-compact, so take a finite affine open cover and put U = ⊔ U_i = Spec B, with q : U → X.
3. **The composite is pure.** In the canonical topology, a sieve generated by a single arrow covers iff the arrow is a universal effective epimorphism (`prop_23180`). Transitivity of the topology then shows that g = f∘q is a universal effective epimorphism. By Prop 1, A → B is pure.
4. **Descend along g.** Given a descent datum (N,θ) on X relative to Y, the pulled-back datum q*(N,θ) relative to g descends by Thm 08XA: there are an A-module M and an isomorphism ψ : g*M ≅ q*N compatible with the descent data on U ×_Y U.
5. **Descend ψ along q.**
   - Restrict ψ to U ×_X U ⊂ U ×_Y U.
   - Along the diagonal X → X ×_Y X, θ restricts to the identity (pull back the cocycle along the diagonal of X×X×X).
   - Hence ψ is compatible with the canonical descent data for the Zariski cover q.
   - So ψ descends to ψ₀ : f*M ≅ N.
6. **Check ψ₀ against θ.** It is enough to check after pullback along U ×_Y U → X ×_Y X. That map is a Zariski open covering (by the U_i ×_Y U_j), so pulling back along it is faithful.
7. Full faithfulness is Thm A. ∎

**Remark.** The proof gives more: if, locally on Y, some quasi-compact open X₀ ⊂ X already has X₀ → Y a universal effective epimorphism, then f is of effective descent. This is Grothendieck's 8840: a morphism through which an effective descent morphism factors is itself of effective descent.

**A compactness lemma (proved, not used later).**

- Let (A → B_j)_{j∈J} be a family such that N → ∏_j N⊗B_j is injective for every N. If every B_j is a Mittag-Leffler A-module (for example, finitely presented), then some finite subfamily is pure.
- Proof:
  - Otherwise, choose for every finite F ⊂ J a pair (N_F, n_F ≠ 0) with n_F killed in N_F ⊗ B_j for all j ∈ F.
  - Choose an ultrafilter on the finite subsets of J containing every {F : j ∈ F}, and let N = ∏_𝒰 N_F (ultraproduct), n = [n_F] ≠ 0.
  - The Mittag-Leffler property makes (∏ N_F)⊗B_j → ∏(N_F⊗B_j) injective, so n dies in every N⊗B_j. Contradiction.
- So a counterexample needs pieces B_j that are not Mittag-Leffler, such as localizations. The example below has exactly this shape.

## 4. The non-quasi-compact case: a counterexample under u = ℵ₁

### 4.1 The Stacks family

Source: Stacks, Examples, Section **0EUE**, *"The spectrum of the integers is not quasi-compact"* (I read the LaTeX source).

Setup:

- P is the set of primes and U a nonprincipal ultrafilter on P.
- For A ∈ U, let S_A be the multiplicative set generated by A, and ℤ_A = S_A⁻¹ℤ. Then Spec ℤ_A = {(0)} ∪ Aᶜ.
- ℤ_A ⊗ ℤ_B = ℤ_{A∪B}.
- ℤ_{{p}ᶜ} = ℤ_(p), and ℤ_P = ℚ.

What Stacks proves:

- **Claim I** (Stacks Lemma **0EUF**): for every ℤ-module M, M = Eq(∏_A M_A ⇉ ∏_{A,B} M_{A∪B}).
- **Claim II**: closed subsets glue.
- With Descent **Lemma 0EUD** (the equalizer condition plus universal submersiveness implies a universal effective epimorphism in Sch), Stacks **Lemma 0EUG** concludes:

  𝒲_U = {Spec ℤ_A → Spec ℤ}_{A∈U}, equivalently f : X = ⊔_{A∈U} Spec ℤ_A → Spec ℤ, is a **universal effective epimorphism in the category of schemes**.

- No finite subfamily is a universal effective epimorphism, because every finite subfamily factors through some Spec ℤ[1/p].

So f is flat, surjective, not quasi-compact, and a covering for the canonical topology. Grothendieck's remark that such coverings are "hard to characterise" is borne out.

### 4.2 Descent data along 𝒲_U

A descent datum along f consists of:

- ℤ_A-modules N_A for A ∈ U;
- isomorphisms φ_AB : (N_A)_{A∪B} ≅ (N_B)_{A∪B};
- the cocycle condition on ℤ_{A∪B∪C}.

Note that X ×_Y X = ⊔ Spec ℤ_{A∪B} and QCoh(⊔) = ∏ Mod.

**Prop 2 (ZFC).** Torsion data and torsion-free data are effective.

- **Torsion data.** If every N_A is torsion, then N_A = ⊕_{p∉A} T_p with T_p := N_{{p}ᶜ}[p^∞]. Then M = ⊕_p T_p descends it.
- **Torsion-free data.**
  1. Put V = N_P and N_(p) = N_{{p}ᶜ} ⊂ V. Over the PID ℤ_A, N_A = ∩_{p∉A} N_(p).
  2. Put M = ∩_p N_(p). Then M ⊂ N_A, so M_A ⊂ N_A.
  3. Fix x ∈ V and let T(x) = {p : x ∉ N_(p)}. For every B ∈ U, write x = y/s with y ∈ N_B and s ∈ ℤ∖0. Then T(x) ∩ Bᶜ ⊂ {p | s}, which is finite.
  4. **Ultrafilter splitting:** if T ∩ Bᶜ is finite for all B ∈ U, then T is finite. (Split an infinite T into two infinite halves; the complement of one half lies in U. This is checked in Lean, below.)
  5. So T(x) is finite. For x ∈ N_A we have T(x) ⊂ A, and some s ∈ S_A gives sx ∈ M. Hence M_A = N_A. ∎

**Prop 3 (ZFC). Exact obstruction.** Let T = ⊕_p ℤ/p, so T_A = ⊕_{p∉A} ℤ/p.

- **Coherent families.** Call a family g = (g_A)_{A∈U}, with g_A ∈ ∏_{p∉A} ℤ/p, *coherent* if g_A − g_B is finitely supported on Aᶜ∩Bᶜ.
- **The datum.** Put t_AB = (g_A − g_B)|_{Aᶜ∩Bᶜ} ∈ T_{A∪B}; this is a 1-cocycle. Define
  N_A = ℤ_A ⊕ T_A,  φ_AB(r, t) = (r, t + r·t_AB).
  This is a descent datum: an extension of 𝒪 by T.
- **Claim: it is effective iff g is trivial**, i.e. iff there is k ∈ ∏_p ℤ/p with g_A ≡ k on Aᶜ modulo finite sets, for all A.
- **Proof of ⇒:**
  1. Suppose (M, α_A) descends the datum. The projections N_A → ℤ_A are compatible.
  2. By Claim I for ℤ, they define π : M → ℤ. Then coker(π)_A = 0 for all A, so coker π = 0.
  3. Choose m with π(m) = 1. Then α_A(m) = (1, h_A) with h_A ∈ T_A *finitely supported*.
  4. Compatibility gives g_A + h_A = g_B + h_B on Aᶜ∩Bᶜ.
  5. These glue to k ∈ ∏_p ℤ/p (every p lies in some Aᶜ, for instance A = {p}ᶜ). So g_A = k − h_A ≡ k.
- **Proof of ⇐:** run the same argument backwards (take M = ℤ ⊕ T twisted by k).
- **Equivalence with an H¹ condition.** The torsion submodule is compatible with localization. Prop 2, plus pulling extensions back along ℤ → F, shows that f is of effective descent for QCoh **iff**, for every family (T_p) of p-primary groups, every U*-coherent family with values in ∏T_p/⊕T_p is trivial.

**Topological translation.**

- Let ω* = βP ∖ P, and view U as a point of ω*.
- Elements C ∉ U correspond to the clopen sets C* ⊂ ω*∖{U}.
- A coherent family of 0/1-valued functions is the same thing as a clopen subset S of the open set O = ω* ∖ {U}.
- Such a family is trivial iff S extends to a clopen subset of ω*.
- A clopen S of O fails to extend iff U lies in the closure of both S and O∖S. That is, iff U is a **strong butterfly point** (both wings clopen, as in Fine–Gillman). Equivalently, ζ(ω*∖{U}) ≠ ω*.
- A 0/1-valued family that is nontrivial as a family of sets stays nontrivial in ∏ℤ/p (put W = {p : k(p) = 1}).

**Butterfly points of character ℵ₁ (ZFC).**

- Fine–Gillman Butterfly Lemma: under CH, every point of ω* is a strong butterfly point (Pitz–Suabedissen, arXiv 1310.0678, Lemma 3.1; I read the proof).
- The proof uses CH only to get a clopen neighbourhood base {U_α : α < ω₁}, together with two ZFC properties of ω*: it is an F-space, and nonempty G_δ sets have nonempty interior. So every point of character ℵ₁ is a strong butterfly point, in ZFC.
- Van Douwen's problem P20 in *Problems from Topology Proceedings* (arXiv math/0312456, read) states this too: "it is known that p is as required [ζ(ω*∖{p}) ≠ ω*] if it has a local base of cardinality ω₁".

**Thm C.** Suppose some nonprincipal ultrafilter U on P is generated by ℵ₁ sets (u = ℵ₁; for example under CH, where every U qualifies).

- Then f : ⊔_{A∈U} Spec ℤ_A → Spec ℤ is a universal effective epimorphism in Sch (Stacks 0EUG).
- It is a descent morphism for QCoh (Thm A).
- It is **not** an effective descent morphism for QCoh. The datum of Prop 3, built from a butterfly clopen of ω*∖{U}, is not effective.
- Consequently, QCoh is a separated prestack but not a stack for the canonical topology on Sch.

**What remains open.**

- Van Douwen–Kunen–van Mill (PAMS 105 (1989); cited via the two papers above) give a model of MA + c = ℵ₂ in which β(ω*∖{p}) = ω* for all p. In that model every 0/1-coherent family is trivial, so the obstruction used in Thm C vanishes for every U.
- Whether 𝒲_U is then effective is open to me. One would need triviality for all coefficient systems (T_p), which C*-embedding does not obviously give.
- Also open:
  - whether some U gives effectivity in ZFC;
  - whether a ZFC counterexample exists, from this family or another.
- The question appears to involve set theory in an essential way.
