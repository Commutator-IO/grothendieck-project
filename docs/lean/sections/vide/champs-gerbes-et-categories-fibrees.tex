\domainevide{Les cotes de ce thème supposent les champs et les gerbes sur un site, que mathlib ne définit pas.}{62, 63, 103, 134-1, 134-2, 134-8}
\noindent Pistes de l'onglet Findings pour ces cotes, hors de portée de Lean pour l'instant :
\begin{itemize}\small\setlength{\itemsep}{0pt}
\item Cote~62 : sur une base où $6$ est inversible, les triplets $(X, X', s)$ formés d'une courbe de genre $0$, d'une trisection étale et d'une section disjointe ont trois descriptions équivalentes, dont un invariant $j$ qui détermine le triplet là où $j(j-1)$ est inversible. Mathlib n'a pas les courbes de genre $0$ sur une base ni leurs trisections étales.\piste{62-triples-rigidified-moduli}
\item Cote~103 : énoncé sans démonstration : pour un Groupe $G$ sur un topos et un $G$-Module $N$, les Gr-champs épinglés par $(G, N)$ correspondent au complexe tronqué $\tau_{\leq 2}(R\Gamma(B_G \bmod X, N)[1])$. Mathlib n'a pas les Gr-champs ni les topos classifiants.\piste{103-gr-stacks-relative-cohomology-BG}
\item Cote~134-1 : heuristique : pour des faisceaux abéliens $M$, $N$ sur un topos, une suite exacte $0 \to \mathrm{Ext}^2(M, N) \to P(M, N) \to \mathrm{Hom}(M, {}_2N) \to 0$, où $P(M, N)$ est le faisceau des champs de Picard épinglés. Mathlib n'a pas les champs de Picard sur un topos.\piste{134-1-picard-sign-sequence}
\item Cote~134-1 : \q{sauf erreur} et sans argument : sur tout topos, tout homomorphisme $M \to {}_2N$ est l'invariant de symétrie d'un champ de Picard épinglé par $M$, $N$. Mathlib n'a pas les champs de Picard ni leurs obstructions dans $\mathrm{Ext}^3$.\piste{134-1-sign-realisation-universal-argument}
\end{itemize}
