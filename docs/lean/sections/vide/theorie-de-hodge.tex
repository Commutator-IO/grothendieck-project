\domainevide{Les cotes de ce thème supposent la cohomologie des variétés kählériennes et les structures de Hodge, absentes de mathlib.}{13, 18}
\noindent Pistes de l'onglet Findings pour ces cotes, hors de portée de Lean pour l'instant :
\begin{itemize}\small\setlength{\itemsep}{0pt}
\item Cote~13 : pour une catégorie tensorielle munie d'un foncteur fibre sur $k$ et d'un autre sur une extension $K$, les éléments de $V$ qui sont dans la $K$-structure sont les invariants d'un sous-groupe algébrique $H$ de $\mathrm{Aut}^\otimes(T)$, sans point base sur le torseur. Mathlib n'a pas les catégories tannakiennes ni les torseurs de foncteurs fibres.\piste{13-double-lattice-invariants}
\item Cote~18 : pour un motif sur $k \simeq \mathbb C$ défini sur un corps de type fini $k_0$, la comparaison des réseaux de Betti entiers en différentes places archimédiennes donne un 1-cocycle de $\mathrm{Gal}(k/k_0)$ dans $G(k)$, dont la classe ne dépend pas de la place. Mathlib n'a pas les motifs, les réseaux de Betti ni la cohomologie galoisienne non abélienne.\piste{18-archimedean-lattice-cocycle}
\end{itemize}
