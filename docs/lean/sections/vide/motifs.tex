\domainevide{Les cotes de ce thème supposent les correspondances algébriques et une catégorie de motifs, que mathlib ne définit pas.}{12, 162-6}
\noindent Pistes de l'onglet Findings pour ces cotes, hors de portée de Lean pour l'instant :
\begin{itemize}\small\setlength{\itemsep}{0pt}
\item Cote~12 : pour une immersion $f : X \to Y$ de source régulière, les constituants de $R^i f_*\mathbb Q_\ell$ sont de poids $\leq 2\inf(i, n)$ et de niveau $\leq \inf(i, n-1)$, où $n$ est la dimension de l'adhérence de $f(X)$. Mathlib n'a pas les poids des faisceaux $\ell$-adiques.\piste{12-immersion-level-bound}
\end{itemize}
