\domainevide{Les cotes de ce thème supposent la descente fidèlement plate pour les schémas, que mathlib ne développe pas.}{126, 128}
\noindent Pistes de l'onglet Findings pour ces cotes, non démontrées ici :
\begin{itemize}\small\setlength{\itemsep}{0pt}
\item Cote~126 : un morphisme fini universellement ouvert $X \to Y$, $Y$ localement noethérien, dont toutes les fibres ont le même nombre de points géométriques, se factorise en un morphisme radiciel fini surjectif suivi d'un revêtement étale fini, universel parmi les morphismes vers les $Y$-schémas étales. Mathlib n'a pas les morphismes universellement ouverts ni cette factorisation étale.\piste{126-radicial-etale-factorisation}
\item Cote~126 : une relation d'équivalence plate $R \rightrightarrows X$ effective modulo un idéal nilpotent, de quotient fpqc quasi-séparé, est effective, et son quotient est un épaississement nilpotent du premier. Mathlib n'a pas les relations d'équivalence plates ni les quotients fpqc.\piste{126-nilpotent-deformation-quotient}
\item Cote~126 : pour $T \to S$ plat de type fini et une catégorie fibrée où les morphismes plats surjectifs sont de descente, une donnée de descente définie sur des ouverts denses devient, après restriction de $T$ à un ouvert dense, une donnée de descente. Mathlib n'a pas la descente dans les catégories fibrées sur les schémas.\piste{126-generic-descent}
\item Cote~128 : dans un carré de Milnor à idéal nilpotent, si $\operatorname{Spec} A'/IA' \to \operatorname{Spec} A/I$ est un morphisme de descente effective pour les modules plats, $\operatorname{Spec} A' \to \operatorname{Spec} A$ l'est aussi, et le reste après changement de base plat. Mathlib n'a pas la descente effective des modules plats.\piste{128-nilpotent-conductor-flat-descent}
\item Cote~128 : pour $A$ local artinien et $A'$ une $A$-algèbre finie à extensions résiduelles triviales, les hypothèses sur l'idéal d'équivalence forcent $\mathrm{long}(A'/A) \leq 1$ ; si $A'/A \simeq A/\mathfrak m$, $\operatorname{Spec} A'$ porte exactement deux relations d'équivalence sur $\operatorname{Spec} A$. Accessible : mathlib a la longueur des modules ; la preuve reste à écrire.\piste{128-colength-one-equivalence-criterion}
\item Cote~128 : le dossier énonce sans démonstration l'équivalence de trois conditions sur les $A'_n/A_n$ (nullité de $H^1$, trivialité de $H^1(-, \mathrm{GL}_r)$, descente effective des modules plats), et qu'elles entraînent la descente effective des modules plats de type fini le long de $\operatorname{Spec} A' \to \operatorname{Spec} H^0(A'/A)$. Mathlib n'a pas la descente ni $H^1(A'/A, \mathrm{GL}_r)$.\piste{128-infinitesimal-descent-theorem}
\end{itemize}
