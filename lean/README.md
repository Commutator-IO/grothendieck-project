# The readings, proved

Lean 4 proofs, against mathlib, of statements the modernised readings make
(issue [#26](https://github.com/Commutator-IO/grothendieck-project/issues/26)).
A proof here says that what a reading states **holds together**, not that it is
what the page says: a perfectly formalised statement can be a perfectly
formalised misreading.

```bash
cd lean && lake exe cache get && lake build   # fails on any warning, so on any sorry
```

Mathlib is pinned to a revision of its `master` (`rev` in `lakefile.toml`, with
the toolchain in `lean-toolchain`), not to a release tag, so that the proofs
are checked against the library the pull requests of issue
[#52](https://github.com/Commutator-IO/grothendieck-project/issues/52) target.
To move the pin: set `rev` to the new SHA, copy `lean-toolchain` from that
Mathlib revision, run `lake update mathlib` (it fetches the cache), then build
the folders one at a time, since a process that imports Mathlib takes about
2 GB and Lake has no option to limit parallelism. A deprecation in Mathlib
fails the build; the compiler names the replacement.

Fifty-seven folders: the eighteen of issue #26 (tier 1, and the five rows of tier 2), and thirty-nine findings of the Findings tab (1, 2, 10, 11, 29, 37, 40, 44, 62, 64, 67, 68, 70, 72, 73, 74, 76, 77, 78, 79, 82, 84, 85, 86, 93, 98, 101, 115, 118, 120, 133, 136, 140-1, 145, 146, 156-1, 156-2, 156-3, 160); folders 21, 22, 136 and 153 also prove part of one finding each, and folder 39 one in full, proved as stated — which says nothing about whether they are in the literature. Each statement, its written-out proof and
what the verification found are in the appendix
[`docs/lean/article.pdf`](../docs/lean/article.pdf), served at
<https://grothendieck.commutator.io/article/grothendieck-lean.pdf>, and on the
site's Findings page. `./axioms.sh`, run after `lake build`, lists the axioms
of every theorem and fails on any beyond Lean's three standard ones.
